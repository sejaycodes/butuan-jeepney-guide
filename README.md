# butuan-jeepney-guide
A community-oriented website that helps residents and visitors navigate Butuan City's jeepney and multicab routes.

The Butuan City Jeepney Route Guide provides route information in one accessible place, including streets traveled, landmarks, directions, and commuter advisories. It aims to make commuting around Butuan City easier, especially for people unfamiliar with the city's public transportation system.

About the Project

Finding the right multicab or jeepney route can be difficult, particularly when route signs provide limited information or actual driver routes differ from the documented route structure.

This project aims to organize available route information into a searchable, easy-to-understand website so commuters can plan their journeys without needing to install a separate application.

# Features

Route Directory — Browse available jeepney and multicab routes.

Route Details — View route origins, destinations, streets, and landmarks.

Directional Information — View westbound and eastbound route structures where available.

Route Advisories — Read warnings about terminal bypasses, shortened trips, and other reported route variations.

Route Maps — Visualize route alignments and important locations.

Fare Information — Provide passenger fare information when verified.

Responsive Design — Access the guide on desktop and mobile devices.

Features are being developed progressively. Availability depends on the current state of the website and the completeness of the underlying route data.

# Technology Stack

HTML5 — Page structure and content.

CSS3 — Layout, responsive styling, and visual design.

JavaScript — Interactive website functionality.

Mapping — Route visualization and geographic data, as implemented.

The project is designed to work as a lightweight website without requiring commuters to download a mobile application.

# Route Information and Accuracy

Route information is compiled from available route plans, published references, mapped streets, and local observations.

However, official route structures may not always match actual driver behavior. Some drivers may skip designated terminals, stop short of the official destination, or follow an alternative street sequence.

To help commuters make informed decisions:

Route advisories identify reported deviations from documented routes.

Unverified fares, stops, and schedules should not be treated as confirmed information.

Route information may change as transportation plans and operating practices evolve.

This website is an independent commuter reference project. It is not an official government or transport-authority website. Always confirm your destination and intended drop-off point with the driver when necessary.

# Running Locally

Clone the repository:

git clone https://github.com/sejaycodes/butuan-jeepney-route-guide.git

Enter the project directory:

cd butuan-jeepney-route-guide

Open index.html in your browser, or use a local development server such as the VS Code Live Server extension.

No build step is required for the basic static HTML/CSS/JavaScript version.

# Deployment

The website can be hosted using GitHub Pages, making it accessible through a public URL without requiring a dedicated server for static content.

Deployment instructions and the published website link will be added when hosting is configured.
